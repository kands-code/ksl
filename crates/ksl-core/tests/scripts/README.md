# 脚本测试

本目录存放 ksl 核心库的功能测试. 一个 `.ksl` 文件是一个用例, 用例以行注释给出期望;
行注释会被词法器忽略, 因此用例本身可以直接用 `ksl run` 运行.
用例由 `crates/ksl-core/tests/scripts.rs` 统一驱动.

支持的单行指令:

- `# @value <文本>`: 执行并比较尾值的默认显示;
- `# @error <错误码>`: 解析, 类型检查或执行应报指定错误;
- `# @exit <退出码>`: 执行应以 `@Exit` 终止;
- `# @check`: 只做类型检查并要求通过;
- `# @run`: 执行并要求成功, 不比较结果.

未写指令时默认按 `@run`. 每个用例只允许一个测试指令. 用例按主题分目录, 同一主题的多个断言应尽量合并到一个
脚本中; 错误用例每个文件只保留一个期望错误.

只有被断言的数据在 ksl 源码层面不可见时才写 Rust 测试, 典型如词法记号序列,
类型表内容, IR 文本形态, 符号驻留表与弱引用状态.
