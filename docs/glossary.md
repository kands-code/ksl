# 术语表

项目文档与代码注释的用词依据. 新术语随文档或代码在同一提交中登记.
正文优先使用中文译名; 中文译名为 `-` 的术语直接使用英文原词.
类型名, 函数名与特殊形式名保留原样, 中文译名只说明含义.
