# 路线图与待确认事项

本文件记录未实现的方向与待确认问题, 不属于设计文档.
当前设计见 `docs/topics/` 下的各篇, 项目定位见 `docs/about.md`.

## 远期方向

- 插件扩展: 平台事件源的注册与唤醒, 图形插件入口与操作系统事件循环集成;
  静态链接插件与主程序共享驻留表.
  当前 ABI 见 `docs/topics/implementation/plugins.md`.
- 字节码与 JIT: 把线性 IR 编译为字节码.
  - 先覆盖纯函数, 调用, 尾调用与分支, 用差分测试与原 `call` 基准确认收益.
  - 达标后扩展到列表, Data, Actor, I/O 与环回收; 未达收益目标时保留线性解释器.
  - 最后评估 JIT 与 AOT, 难点在续延与 Actor 恢复点的调用约定, 堆对象布局与运行时 ABI.
- LSP 扩展: 在现有最小 LSP 服务上补充定义跳转与补全.
- 原生编译: 全语言单态, 无 trait 与子类型, 代码生成可使用 typed IR 或类型表.
  - 运行时 `Value` 不需要完整类型标签; 若引入反射或动态分派, 再评估运行时类型表示.
- 定时调度: cron 表达式解析与内置调度器暂不引入.
  - 用户可在 Actor 内用 `@SetTimer` 与时间原语自行搭建调度循环.
  - 若引入, 内置下一次触发时刻优先于内置完整调度器;
    后者须确定系统时钟被调整时的重算时机, 以及错过触发是补发还是跳过.
  - 表达式方言以 croner 一类库的常用子集为准, `L`/`W`/`#`/`?` 等扩展不作承诺.
- 网络: 在现有明文 TCP 原语上补充 UDP, 主机名解析, TLS, 长度前缀分帧与更高层协议.
  这些能力优先以原语加 `.ksl` 模块实现, 不急于引入独立标准库.
- 流式进程: 暂缓.
  - 一次性命令执行已覆盖程序启动, 输出捕获与退出状态.
  - 边读边写, 超时, 取消与交互式终端需要 `Process` 原语, 届时再评估; PTY 支持另算.
- 分布式: 远期目标之一, 网络通信与跨进程交互是后续重点.
  - Pid 是节点内标识, 不跨进程传递; 透明跨节点 Pid 是独立议题,
    涉及 Pid 身份, 消息序列化, 节点管理与故障语义.
  - 消息已建模为语言值, 分布式协议可以沿用这一前提.
- 事件泵: 增加主动唤醒机制, 替代固定间隔轮询.

## 性能优化

纯内置调用与同步原语已融合为块内指令, 见 `docs/topics/implementation/architecture.md` 第 4 节.
基准与当前测量见 `bench/README.md`.

- 非尾用户调用的续延融合.
  - 当前续延以目标基本块表示, 调用返回必须切换基本块.
  - 可选方案是把续延扩展为基本块加指令下标, 返回时直接继续执行;
    代价是活跃变量分析与槽位分配要覆盖块内恢复点.
- 列表高阶操作的续延往返.
  - `@ListMap`, `@ListFold` 与 `@ListFilter` 每处理一个元素都经过一次续延帧入栈与出栈.
  - 逐元素索引查找已不是瓶颈, 可选方向是为闭包调用建立专门的循环路径,
    或把列表游标与续延帧合并.
- `@DictGet` 降级产生的参数拷贝.
  - 字典与键在降级时绑定到临时槽位, 即使实参是原子表达式.
  - 可选方案是按原子实参直接传递, 与实参降级的现有规则保持一致.
- `DictLookup` 与立即 `@Match` 的专门化.
  - 每次命中都会构造一个 `Option` Data 值, 随后立即解构.
  - 可选方案是在降级期识别该模式, 直接生成带成功与失败分支的原语.
- 值搬运与指令分派.
  - 操作数求值仍逐次克隆 `Value`, 槽位与实参缓冲之间存在拷贝.
  - 可选方案是与字节码方向合并评估, 用更紧凑的操作数编码减少中间槽位.

## 待确认事项

- 待确认: 长原生原语是否按输入规模计入预算.
  - `run_budget` 只按 IR 指令计数, 字符串, 排序, 正则与集合构造等原生操作在一个指令内完成.
  - 可选方案是按输入规模计预算, 或把长操作改写为续延驱动的增量循环.
- 待确认: 内置函数元数据与实现的单一来源.
  - `ksl-catalog` 维护名字与签名, `ksl-runtime` 维护实现, 两份清单按位置对应并由测试校验.
  - 可选方案是把元数据下沉到运行时, 前端通过 trait 查询; 代价是跨 crate 查询路径与模块边界调整.
- 待确认: 运行时值表示是否简化.
  - `List` 有 7 种存储变体, `Value` 维持 16 字节约束.
- 待确认: 是否拆出独立 `ksl-ir` crate.
  - CPS 树 IR, 线性 IR 与运行时同 crate; 拆分可降低耦合, 但会增加跨 crate 类型边界.
- 待确认: 标准库的形态.
  - 暂缓独立标准库, 倾向把常用能力作为内置函数与特殊形式提供, 避免跨平台模块搜索路径.
  - 内置集合扩展到什么程度, 需要在真实示例中评估.
- 待确认: 分布式 Actor 的形态.
  - 跨进程通信统一由网络功能实现.
  - 透明跨节点 Pid 与显式远程消息两条路线留待分布式阶段评估.
- 待确认: REPL 长会话是否回收历史状态.
  - 当前不设上限: REPL 主要用于非 Actor 与非模块功能的局部测试与快速演示, 长期驻留风险较低.
  - 若后续出现长时间会话需求, 再评估按输入数量或内存上限回收源码集合, 类型表与模块缓存.
