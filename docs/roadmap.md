# 路线图

未实现的方向与待确认事项. 语言规则与实现见 `docs/topics/`, 项目定位见 `docs/about.md`.

## 1. 方向

### 1.1 插件

- 平台事件源注册与唤醒, 图形插件入口与操作系统事件循环集成.
- 插件能力:
  - 回调. 参数中的 `Fn` 以借用令牌传入, 插件在本次调用内同步调用 ksl 闭包.
    令牌只在接收它的入口调用期间有效, 只能在同一线程使用; 回调体不得挂起或产生效果.
    跨线程与可保存的回调另行评估, 音频回调类接口把逻辑留在包装层.
  - 借用句柄. 在 `NativeOpaque` 或导出宏中区分拥有与借用, 让子对象可以借用返回.
    导出宏只返回拥有句柄, 子对象只能用访问器暴露.
- raylib 示例:
  - Game of Life 侧栏与控件. 当前侧栏显示 FPS 与提示, 键盘控制; 可选矩形按钮与点击测试, 不引入 raygui.
  - raymath. 按示例需要补 Vector3, Matrix 与 Quaternion 的常用子集, 不一次映射全部函数.

### 1.2 执行与编译

- 字节码. 把线性 IR 编译为字节码, 先覆盖纯函数, 调用, 尾调用与分支,
  用差分测试与 `call` 基准确认收益. 达标后扩展到列表, Data, Actor, I/O 与环回收;
  收益不足时保留线性解释器.
- JIT 与 AOT. 在字节码之后评估. 难点是续延与 Actor 恢复点的调用约定,
  堆对象布局与运行时 ABI.
- 原生编译. 全语言单态, 无 trait 与子类型, 代码生成可直接使用 typed AST 或类型信息.
  运行时 `Value` 不需要完整类型标签; 若引入反射或动态分派, 再评估运行时类型表示.
- 事件泵. 增加主动唤醒机制, 替代固定间隔轮询.

### 1.3 语言与工具

- `@Let` 直接解构 Pair 与单变体 Data, 不必先绑定再 `@Fst` 或 `@Match`.
  需要确定嵌套层级与模式合法性; 绑定目标只接受名字, 标注与 `_`.
- 编辑器高亮. REPL 与 MT 对齐 tree-sitter, 补限定名, 声明名与分隔符着色;
  暂不做定义跳转与补全.
- 定时调度. 暂不引入 cron 解析与内置调度器,
  用户可以在 Actor 内用 `@SetTimer` 与时间原语搭建调度循环.
  若引入, 优先提供"下一次触发时刻"内置, 再考虑完整调度器;
  后者须确定系统时钟调整后的重算时机, 以及错过触发是补发还是跳过.
  表达式方言以 croner 一类库的常用子集为准, 不支持 `L`, `W`, `#`, `?` 等扩展.
- 网络. 在明文 TCP 原语上补充 UDP, 主机名解析, TLS, 长度前缀分帧与更高层协议.
  优先以原语加 `.ksl` 模块实现, 不引入独立标准库.
- 流式进程. 需要 `Process` 原语支持边读边写, 超时, 取消与交互式终端.
  一次性命令执行已覆盖程序启动, 输出捕获与退出状态; PTY 支持另算.
- 分布式. 网络通信与跨进程交互是远期重点.
  Pid 是节点内标识, 不跨进程传递.
  透明跨节点 Pid 与显式远程消息是两条候选路线, 涉及 Pid 身份, 消息序列化,
  节点管理与故障语义. 消息已建模为语言值, 分布式协议可以沿用这一前提.

## 2. 性能

同步内置函数与同步原语在降级时直接成为块内指令,
见 `docs/topics/implementation/ir.md` 第 2 节.
基准与测量结果见 `bench/README.md`.

- 非尾用户调用的续延融合. 续延以目标基本块表示, 调用返回必须切换基本块.
  候选方案: 把续延扩展为基本块加指令下标, 返回时直接继续执行.
  代价是活跃变量分析与槽位分配要覆盖块内恢复点.
- 列表高阶操作的续延往返.
  `@ListMap`, `@ListFold` 与 `@ListFilter` 每处理一个元素都经过一次续延帧入栈与出栈.
  逐元素索引查找不是瓶颈. 候选方案: 为闭包调用建立专门的循环路径,
  或把列表游标与续延帧合并.
- `@DictGet` 降级产生的参数拷贝. 字典与键在降级时绑定到临时槽位, 即使实参是原子表达式.
  候选方案: 按原子实参直接传递, 与实参降级的现有规则保持一致.
- `DictLookup` 与立即 `@Match` 的专门化. 每次命中都会构造一个 `Option` Data 值,
  随后立即解构. 候选方案: 在降级期识别该模式, 直接生成带成功与失败分支的原语.
- 值搬运与指令分派. 操作数求值仍逐次克隆 `Value`, 槽位与实参缓冲之间存在拷贝.
  候选方案: 与字节码方向合并评估, 用更紧凑的操作数编码减少中间槽位.

## 3. 待确认事项

- 待确认: 长原生原语是否按输入规模计入预算.
  `run_budget` 只按 IR 指令计数, 字符串, 排序, 正则与集合构造等原生操作在一个指令内完成.
  候选方案: 按输入规模计预算, 或把长操作改写为续延驱动的增量循环.
- 待确认: 内置能力的范围.
  不设独立标准库, 常用能力作为内置函数与特殊形式提供, 避免跨平台模块搜索路径.
  内置集合与字符串操作扩展到什么程度, 按真实示例评估.
- 待确认: 分布式 Actor 的形态.
  跨进程通信统一由网络功能实现. 透明跨节点 Pid 与显式远程消息两条路线留待分布式阶段评估.
- 待确认: REPL 长会话是否回收历史状态.
  不设上限. REPL 主要用于非 Actor 与非模块功能的局部测试与快速演示, 长期驻留风险较低.
  若出现长时间会话需求, 再评估按输入数量或内存上限回收源码集合, typed 程序与模块缓存.
