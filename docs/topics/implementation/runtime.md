# ksl 运行时表示

`ksl-value` 中的 `Value` 内存表示, 名字与全局环境.
执行模型见 `docs/topics/implementation/scheduler.md`,
IR 命名与降级见 `docs/topics/implementation/ir.md`.

## 1. 值表示

`Value` 体积为 16 字节, 大于指针的变体一律用 `Arc` 包裹.
列表用 imbl 的持久化向量并以 `Arc` 包裹;
`List[i64]`, `List[i32]`, `List[u8]`, `List[u32]`, `List[u64]`, `List[f32]`, `List[f64]`,
`List[char]` 与 `List[bool]` 使用紧凑元素存储.
string 用 `ArcStr`, Data 值与闭包用 `Arc` 包裹.

- 闭包捕获只克隆 `Value`, 递归定义使用写一次单元;
  用户数据不使用内部可变性.
- 宿主资源统一为 `Value::NativeOpaque`; 内置资源与原生插件资源都实现 `NativeOpaque`.
  内置资源包括文件, 命令输出, 套接字, 监听器, 时间, 正则与匹配结果, 具体类别由资源类型区分.
  外来函数保留 `ForeignFn` 变体.
- Actor 句柄与不透明值内部的 I/O 资源由运行时内部同步.
- `Value` 是 `Send + Sync`; 值拷贝为 O(1); imbl 的节点级结构共享.
- 续延帧是堆上结构; ksl 递归不消耗 Rust 原生栈.
- 变体载荷不超过 8 字节; string 的 `ArcStr` 是单指针, 与判别位共占 16 字节.

## 2. 名字与全局环境

名字: 标识符与类型名使用 `Name`, 基于 `SmolStr`.
22 字节以内内联, 更长的共享堆分配; 克隆为内联拷贝或引用计数递增.
名字自包含, 不依赖进程级驻留表, 比较与哈希按文本内容进行.
宿主与插件各持一份运行时副本时, 名字仍可直接比较.

IR 命名: 源码标识符, 函数名, Data 类型与变体名, 模式字段直接使用 `Name`;
合成临时值与续延使用单调编号 `TempId` 与 `ContId`.
函数表以 `Name` 为键, 显示时直接使用名字文本.
入口函数使用源码不可表达的 `$main`, 不与用户函数同名.
运行时全局环境只为源码名建索引, 合成临时值与续延在降级期解析为槽位与捕获下标.

全局变量按名存取于持久化全局环境; 类型检查与 IR 降级无状态;
REPL 跨行增量定义成立. 顶层绑定统一按全局存储处理, 批处理与交互共用一条路径.
