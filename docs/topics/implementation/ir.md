# ksl 中间表示

typed AST 降级后的 CPS IR 与线性 IR.
降级输入与类型检查见 `docs/topics/implementation/architecture.md` 第 3 节,
执行器与调度见 `docs/topics/implementation/scheduler.md`,
运行时值表示见 `docs/topics/implementation/runtime.md`.

## 1. CPS IR

`ksl-ir/src/lower` 把 typed AST 降级为函数级 CPS 形式, 模型位于 `ksl-ir/src/cps`.
每个函数带续延参数 `$k`; 尾调用, 普通调用, 续延绑定, `receive` 挂起点与 `continue` 都显式可见.

同步内置函数与同步原语的求值使用 `Eval` 节点, 直接绑定结果并继续, 不创建续延;
`call` 与 `prim` 只用于会挂起或回调用户函数的操作.

该树形形态是线性化的输入, `ksl cps` 输出它供调试.
模块分别保存顶层语句体与 `@Main` 入口; 入口单独降级为 Handler 函数, 供调试与降级使用.
IR 节点保留源码区间供运行时错误定位.

## 2. 线性 IR

`ksl-ir/src/linear` 把 CPS 树线性化为基本块.
每个块带参数, 顺序指令与唯一终止指令.

- `Instr` 覆盖绑定, 同步求值, 顶层绑定与递归绑定;
  `Terminator` 覆盖返回, 跳转, 调用, 原语, 接收, 分支与 Actor 终止.
- 线性化后完成闭包转换: 函数按后序登记, 被引用函数的自由变量已收集;
  线性化当前函数时同时收集其自由变量. 随后计算基本块活跃变量,
  把变量引用解析为槽位或捕获下标, 跳转与调用显式传递活跃参数.
- 续延是目标基本块; 运行时按槽位与捕获下标取值, 不维护名字环境与续延表.
- 块内指令连续执行, 到终止指令或预算耗尽时回到调度器; 超长基本块不会独占调度.
- 同函数块切换原地复用槽位缓冲, 非参数槽位在块内先写后读.
  同步内置函数与同步原语在线性化时直接生成块内指令, 不建续延帧;
  需要回调用户函数或调度器效果的操作才建立续延帧.
- 同步原语指令标注执行后不再读取的槽位, 运行时先清空这些槽位,
  使容器实参保持唯一.
- `ksl linear` 输出该形态. 该形态保留槽位名, 槽位类型, 函数签名与数据声明,
  供查看与测试使用; 执行器不直接使用它.

### 2.1 执行视图

`Module::into_plan` 把线性 IR 转为 `ksl-plan` 的 `Program`, 执行器只接受该形态.
`ksl-ir::linear::plan` 重新导出这些执行视图类型; 运行时直接依赖 `ksl-plan`.

- 函数与基本块去掉展示数据, 只保留入口块, 槽位个数, 指令与终止指令.
  转换消费 `Module`, 槽位名与类型随之释放; REPL 中全局闭包不再持有这些数据.
- 槽位个数是运行时分配槽位缓冲的唯一依据, 参数个数与槽位个数均为 `usize`.
- 顶层函数的捕获名随执行视图保存, 启动时从全局环境播种;
  其余函数通过 `Operand::Func` 与递归绑定显式携带捕获.
- 入口函数 `@Main` 与数据声明只参与查看, 不进入执行视图.

## 3. 编译期栈安全

CPS 降级按语句序列回卷, 线性化使用显式工作栈,
释放 CPS 树时逐节点展开; 长列表字面量与长语句序列不随长度加深调用栈.
parser 对表达式与类型设 64 层嵌套上限, 检查器的递归深度随之有界.
模块加载用显式帧栈完成深度优先遍历, 依赖链长度不消耗 Rust 调用栈.
