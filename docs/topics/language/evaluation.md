# ksl 求值与绑定

ksl 的求值模型, 以及绑定与作用域规则.
语法形式见 `docs/topics/language/syntax.md`, 类型规则见 `docs/topics/language/types.md`,
函数与闭包见 `docs/topics/language/functions.md`.

## 1. 求值模型

常规调用采用传值调用: 参数从左到右求值, 然后进入函数.
特殊形式直接接收抽象语法树的节点, 由实现决定参数的求值时机.
用户不能延迟求值, 也不能引用未定义的内容; 未求值参数的能力完全封闭在解释器内部.

语言采用值语义. 绑定一旦建立就不再改变, 状态更新通过生成新值完成.
因此结构上不会出现别名, 只有一种拷贝规则, 不区分浅拷贝与深拷贝.
实现层使用持久化数据结构.

- 不可变只约束用户数据. 输出, 文件与消息等系统副作用不受此限制.
- 多个 Actor 需要共享可变状态时, 由一个 Actor 持有状态,
  其他 Actor 通过消息查询和更新, 即唯一所有者.
- 值本身不会形成环. 列表与 Data 值在类型约束与值语义下不可能成环;
  闭包自引用与 Actor 句柄可能形成引用环, 运行时用 Arc 引用计数加显式环回收处理.

## 2. 绑定

`@Let[名字 : 类型, 值]` 建立绑定, 标注可以省略.

- 值绑定, 即 `@Let` 与具名 `@Def`, 可以遮蔽外层同名绑定.
  类型声明不可覆盖, 重复声明或使用内置名直接报错.
- `@Let` 一次只引入一个绑定, 不提供并行绑定形式.
  需要同时求值多个表达式时, 先构造配对或列表, 再用 `@Let` 逐条绑定.
- 绑定不可变, 因此没有修改绑定的原语, `@Mutate` 不存在.
  状态更新通过生成新值并重新绑定完成; 重新绑定即遮蔽, 先前绑定已建立的值不受影响.

```ksl
@Let[x, 10];
@Let[x, AddI64[x, 5]];
Print[f"x = {x}\n"];
```

第二条 `@Let` 读取上一条绑定的 `x`, 遮蔽后新值是 15, 后续语句看到 15.

## 3. 语句值

隐式丢弃只对 nil 与 never 类型放行. 非 nil 值的语句必须显式绑定, 或以 `@Let[_, 值]` 显式丢弃.
交互输入与代码输入的尾表达式不受此约束, 其值即程序值; 模块顶层没有值, 尾表达式按语句处理,
见 `docs/topics/language/modules.md` 第 4 节. `@Block` 内的非末句同样适用本条.

- `@Let[_, 值]` 是显式丢弃: 值按常规检查并执行, 结果直接丢弃.
  空列表与未定类型参数不因丢弃而豁免, 例如 `@Let[_, {}]` 与 `@Let[_, Option/None[]]` 仍报错.
- `_` 是特殊丢弃记号, 不能作为普通标识符引用.
  它可以出现在 `@Let` 的绑定位与 `@Match` 的字段忽略位.
- 顶层最后一条声明也可以省略分号, 值仍为 nil.

## 4. 作用域

`@Block[语句, 语句, ...]` 定义作用域块, 语句以逗号分隔, 块的值为最后一条语句的值.
块内新定义对外层不可见. 空 `@Block[]` 的值为 nil.

- 定义与绑定只产生 nil, 可以出现在顶层或 `@Block` 的语句位置.
  `@Data` 仅限顶层; 普通表达式位置不能定义或绑定.
- 迭代不使用循环原语: 没有 `@While`, 迭代一律以递归表达.
  尾递归经 CPS 变换后不增加栈深度.

## 5. 条件分支

`@If[condition, then, else]` 的条件必须为 bool.
两个分支与结果共享同一类型变量; 有期望类型时, 结果先与期望统一, 统一失败时报错.
详见 `docs/topics/language/types.md` 第 4 节.
`@If` 的分支体可以是 `@Block`.

`@Which[{(condition, value), ...}, fallback]` 按顺序求值条件, 只求值第一个命中分支的值;
没有条件为真时求值 fallback. 条件为字面量 `true` 或 `false` 时报错.
详见 `docs/topics/library/special-forms.md` 第 2 节.
