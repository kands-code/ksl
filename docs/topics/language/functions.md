# ksl 函数与闭包

ksl 的函数定义形态, 递归规则与闭包捕获语义.
绑定与作用域见 `docs/topics/language/evaluation.md`, Data 类型见 `docs/topics/language/data.md`,
Actor 蓝图见 `docs/topics/language/actors.md`.

## 1. 匿名函数

匿名函数用 `@Fn` 定义, 是表达式, 值是函数本身.

- 形态为 `@Fn[[x : i64] : i64, 体]`; 参数类型与返回类型必须标注.
- 多语句体使用 `@Block`.
- 匿名函数不自递归. 用 `@Let[f, @Fn[[...] : ..., 体]]` 绑定时,
  函数体不能引用 `f`.

## 2. 具名函数

具名函数用 `@Def` 定义, 是语句, 在当前作用域绑定函数名, 值为 nil, 默认自递归.

- 形态为 `@Def[名字, [x : i64] : i64, 体]`.
  签名本身就是类型来源, 无需额外标注.
- 具名函数与匿名函数的类型都是 `Fn[[参数类型...] : 返回类型]`.
  对非递归函数, `@Let[f, @Fn[...]]` 与 `@Def[f, ...]` 的类型与调用行为相同;
  `@Def` 的闭包另外保留名字用于显示, 该名字在函数体内可见.
  同一函数的参数名必须互不相同.

## 3. 互递归

函数默认不允许前向引用. 互递归用 `@Fix` 表达.

- `@Fix[定义, 定义, ...]` 只接受具名 `@Def`, 不产生新作用域.
- 组内名字相互可见. 定义本身进入当前作用域, 在 `@Fix` 之后的同块语句中可用,
  随所在块结束而消失. 空 `@Fix[]` 视为 nil.
- `@Fix` 只接受函数定义, 语法不允许递归值定义, 因此不设运行时的未初始化值检查.

```ksl
@Fix[
  @Def[isEven, [n : i64] : bool,
    @If[EqualI64[n, 0], true, isOdd[SubI64[n, 1]]]],
  @Def[isOdd, [n : i64] : bool,
    @If[EqualI64[n, 0], false, isEven[SubI64[n, 1]]]]
];

@Let[a, isEven[10]];
@Let[b, isOdd[10]];
Print[f"isEven[10] = {a}, isOdd[10] = {b}\n"];
```

## 4. 闭包

闭包按值捕获自由变量, 即复制定义时刻的值进入闭包环境, 不共享引用.
自引用闭包会形成引用环, 由运行时的显式环回收处理.

闭包转换与自由变量收集见 `docs/topics/implementation/ir.md` 第 2 节.
