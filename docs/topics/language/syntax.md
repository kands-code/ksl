# ksl 语法

ksl 的词法与语法规则, 以及记号与字面值的形态.
类型规则见 `docs/topics/language/types.md`, 求值与绑定规则见 `docs/topics/language/evaluation.md`,
内置函数与特殊形式的清单见 `docs/topics/library/builtins.md`.

## 1. 调用形式

ksl 只有一种调用形式: 前缀调用加方括号, 函数名之后直接写 `[参数, ...]`.

- 任意表达式之后都可以继续写多组 `[参数]`. 每一组都是完整调用, 不是柯里化.
  调用时先求值被调用表达式, 再从左到右求值参数.
- 只有函数类型的值可以调用, 非函数值与 never 值的调用在类型检查阶段报 `NotCallable`.
  语法层不限制被调用表达式的形状.
- 不提供中缀表达式, 因此没有优先级与结合性, 也没有分组括号.
  圆括号只用于配对记号, 例如 `(1, 'a')`.
- 特殊形式以 `@` 前缀区分, 例如 `@If[condition, then, else]`.
  特殊形式由解释器硬编码分派, 不引入属性机制.
- 不支持元编程, 不提供 quote.

## 2. 语句与结构

顶层形式以分号分隔. 最后一条形式可以省略分号.
交互输入与代码输入中, 尾表达式的值即程序值: REPL 直接展示, `run --code` 求值后丢弃.
模块文件没有值, 最后一条形式按普通语句检查, 非 nil 必须显式绑定或丢弃.
尾表达式仍按常规类型检查.

- 声明形式的值是 nil.
- `@Block` 内的语句以逗号分隔, 块的值是最后一条语句的值.
- 逗号分隔的列表不接受尾逗号. 元素之间写逗号, 最后一个元素后直接写闭括号.
- `#` 引导行注释至行尾. 不提供块注释.

## 3. 标识符与记号

标识符的首字符为 Unicode XID_Start, 或一个以上下划线后接 XID_Start;
后续字符为 XID_Continue. 纯下划线序列不是标识符, 而是特殊的丢弃记号 `_`.

- 内置函数名, 特殊形式名, 字面关键字与内置类型名都是保留名.
- 内置 Data 类型的变体名不保留, 通过类型限定名区分.
- `(a, b)` 是通用配对记号, 表示一个二元值. `@Match` 分支与 `@Use` 重命名都使用这种形式.
- `^类型名` 把类型引入值位置, 用于 `@Export` 与 `@Use` 的类型条目;
  重命名条目写成配对形式. `@Spawn` 的信箱类型由 Handler 的 Pid 类型决定, 不使用类型提升.
- 类型限定名写作 `类型名/名字`, 例如 `Option/Some` 与 `Shape/Circle`.
  省略类型限定的形态以 `/` 开头, 只出现在模式位置, 例如 `(/Circle[r], ...)`.
- 内置函数与特殊形式的命名约定见 `docs/topics/library/builtins.md` 第 1 节.

## 4. 字面值

### 4.1 数值字面值

- 整数字面值默认为 i64. 带 `u` 后缀且值在 u8 范围内为 u8,
  带 `U` 后缀且值在 u64 范围内为 u64, 超出对应范围报错.
  期望类型不改变无后缀整数的类型, u8 与 u64 位置必须显式写对应后缀.
- 十六进制与二进制字面值分别带 `0x` 与 `0b` 前缀, 十六进制数字大小写均可.
  两者都允许 `u` 与 `U` 后缀. 无符号类型没有负值, 负号配无符号后缀非法;
  值域检查与前述规则相同.
- 一元正负号是字面值前缀, 必须紧贴数字. `-12` 合法, `- 12` 非法.
- 指数允许小写 `e` 与大写 `E`. 含小数点或指数的数值字面量为 f64.

### 4.2 字符与字符串字面值

- 字符字面量写作 `'a'`, 取 Unicode 标量值.
- 字符串字面量写作 `"text"`, 取 UTF-8 编码后的文本.
- 原始字符串与 Rust 相同, 使用 `#` 界定, 例如 `r"32131"` 与 `r##"12#121"##`.
- string 是独立类型, 区别于 `List[char]`;
  二者的互转由 `StringToChars` 与 `CharsToString` 提供.

### 4.3 布尔, nil 与容器字面值

- 布尔字面量为 `true` 与 `false`.
- nil 是普通值, 可以绑定, 存入列表与 Data, 作为参数, 作为返回值.
- 列表字面量使用花括号, 例如 `{1, 2, 3}`. 元素类型不一致在类型检查时报错.
- 字典字面量写作 `@Dict[(键, 值), ...]`, 集合字面量写作 `@Set[值, ...]`.
  空字面量需要期望类型或标注, 例如 `@Let[d : Dict[string, i64], @Dict[]]`.
  重复键在 Dict 中后写覆盖先写.

### 4.4 格式化字符串

- 格式化字符串写作 `f"..."`.
  花括号内仅允许变量或字面值, 不允许其他表达式; 转义使用 `{{` 与 `}}`.
  其余细节与 Rust 相同.
- 格式参数文法为 `[[fill]align][sign][#][0][宽度][.精度][类型]`.
  宽度上限为 256, 精度上限为 24, 单位均为十进制字符数, 超限报 `InvalidFormatSpec`.
- 排版部分的含义如下:

  | 部分  | 含义                                                   |
  | ----- | ------------------------------------------------------ |
  | fill  | 填充字符, 缺省为空格; 给出 align 时生效                |
  | align | 对齐方式, `<` 左对齐, `>` 右对齐, `^` 居中, 缺省右对齐 |
  | sign  | `+` 为非负数也写出加号, `-` 与省略等价                 |
  | `#`   | 整数写出进制前缀, 十六进制为 `0x`, 二进制为 `0b`       |
  | `0`   | 宽度不足时用 0 填充, 位置在符号与进制前缀之后          |
  | 宽度  | 最小字符数, 进制前缀计入宽度                           |
  | 精度  | 小数位数, 仅 f64 有效                                  |

  `0` 标志优先于 fill 与 align.
  十六进制与二进制的前缀恒为小写, `X` 只改变数字的大小写.
  整数写出精度报 `InvalidFormatSpec`.
  进制格式保留负号.
  类型后缀位于末尾并计入宽度.
  整数示例: `f"{255:#010x}"` 写出 `0x000000ff`, `f"{-255:#x}"` 写出 `-0xff`,
  `f"{255u:>6}"` 写出 `  255u`.

- 类型字符按值类型限定: i64, u8 与 u64 支持 `x`, `X`, `b`;
  f64 支持 `e`, `E`; string 与 char 支持 `?`.
  不支持八进制. 显式写冒号但参数为空, 例如 `f"{s:}"`, 报错;
  默认输出写 `f"{s}"`.
  string 与 char 不接受 `?` 以外的格式参数.
- 可打印类型为基础值: i64, u8, u64, f64, bool, char, string, nil.
  Pid 可作为顶层值打印, 但不作为 List 与 Pair 的基础元素.
  List 与 Pair 仅当元素或分量为上述基础值时允许打印, 且不支持嵌套.
  例如 `List[i64]` 与 `Pair[i64, string]` 允许,
  `List[List[i64]]` 与 `List[Pair[i64, string]]` 不允许.
  List 与 Pair 不接受格式参数.
- Data, Option, Result, Dict, Set 与不透明类型 File, CommandOutput, DateTime, Socket,
  TcpListener, Regex, RegexMatch 不可打印.
  需要打印这些类型时, 用户自行实现格式化函数.
- 函数, Handler 与闭包可显示签名:
  匿名闭包为 `Fn[[参数类型] : 返回类型]`,
  具名函数为 `函数名 : Fn[[参数类型] : 返回类型]`, 内置函数同理,
  外来函数按链接名与 `@Link` 中的声明签名显示, 例如 `add : Fn[[i64, i64] : i64]`,
  Handler 为 `Handler[[参数类型] : 返回类型]`.
  特殊形式不是值, 不参与打印.
- 嵌入规则: f-string 中顶层 string 默认省略引号, `{s:?}` 显式要求引号;
  顶层 char 默认不带单引号, `{c:?}` 显示单引号;
  bool 原样打印; List 与 Pair 内的字符串和字符始终带引号.
- 默认渲染: u8 输出带 `u` 后缀, 例如 `42u`; u64 输出带 `U` 后缀, 例如 `42U`;
  f64 的有限值带小数点或指数, 例如 `1.0`, 非有限值输出 `inf` 与 `NaN`;
  Pid 输出 `<Pid 1>`, 其中的编号与 `@PidSerial` 一致.
